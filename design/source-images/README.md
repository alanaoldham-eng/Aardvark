# Source images

Full-size original artwork (Ideogram exports, photos, mockups) goes here.
This folder is **not** published to aardvarkgroom.com. Claude makes small,
web-ready copies in `assets/` for the site and app to use.

Tip: name files after what they show, e.g. `cat-nail-trim.png`.
Don't put private material here (customer photos, signed documents): the repo itself is public.
